# Personal guidance

My personal skills live in `~/DEV/skills` (symlinked to
`~/.config/agents/skills`). Load the relevant skill before acting, without
waiting to be asked:

* `managing-skills`: whenever I state a preference or standing rule, correct
  how you work, define a style or standard, or ask to change skills. Record
  it in the skills repo, commit, and always mention the update in chat.
* `writing-commits`: before staging, committing, or planning commits in any
  git repository, or creating one.
* `formatting-code`: before writing or editing code in any language or
  Markdown documents, and when deciding whether to reformat existing code.

## Local-only skills

Private skills that must not be published live outside this repo, in
`~/.agents/skills/` (a separate local git repo, never pushed). Amp loads them
like the skills above; follow them the same way.
